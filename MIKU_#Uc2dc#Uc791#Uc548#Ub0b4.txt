MIKU 전용 수정판 시작 안내

1. ZIP을 풀고 VS Code로 Project-MIKU-feat-demo-login 폴더를 엽니다.
2. .env.example 파일을 복사해 같은 위치에 .env 파일을 만듭니다.
3. .env에서 OPENAI_API_KEY에 본인의 키를 입력합니다. 채팅이나 공유 파일에 키를 올리지 마세요.
4. 터미널에서 npm install 실행 후 npm start 실행합니다.
5. 터미널에 출력된 로컬 주소로 브라우저를 엽니다. 기본 포트는 25565입니다.
6. 브라우저에서 모델이 보이지 않으면 client/assets/models/live2d/yinlang/yinlang.model3.json과 해당 모델이 참조하는 텍스처, moc3 등이 실제로 있는지 확인합니다. 이 ZIP에는 Live2D 모델 실물 파일이 포함되지 않았습니다.
7. 이미 로그인/기존 설정을 저장한 브라우저라면 이전 모델 선택이 남아 있을 수 있습니다. 새로고침 후 다시 확인하세요.

수정 내용: 은랑만 등록, AI 이름 MIKU, 사용자 말투 따라가기, 두 문제 지도 자료, OpenAI 대화 프로바이더, 이미지 첨부 전달.
주의: API 호출/Live2D 렌더링은 이 환경에서 실제 검증하지 못했습니다. OpenAI 모델 접근 권한 및 과금 설정이 필요합니다. 다른 UI/도구 기능과 충돌 가능성이 있으니 원본 ZIP은 백업하세요.
