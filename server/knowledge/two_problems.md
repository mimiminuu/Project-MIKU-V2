# MIKU 전용 두 문제 지도 자료

## 워크북 80쪽 8번
문제: f(x)=-3x^4+4(a-1)x^3+6ax^2 (a>0). g(t)는 x≤t에서 f(x)의 최댓값. g가 모든 실수에서 미분가능하도록 하는 a의 최댓값을 구하라.

지도 흐름:
1. a의 최댓값을 찾으려면 a가 만족할 조건을 먼저 파악하도록 질문한다.
2. g(t)가 누적 최댓값이라는 뜻을 확인하고 f의 그래프가 필요한 이유를 유도한다.
3. f'(x)=-12x(x+1)(x-a)이므로 임계점 -1, 0, a를 찾게 한다.
4. 양쪽 극대값의 높이를 비교해 a=1, a>1, 0<a<1로 나눈다. f(-1)=1+2a, f(a)=a^4+2a^3이다.
5. 누적 최댓값 g의 그래프에서 최대값을 갱신하는 순간의 좌우 기울기가 일치하는지 검사한다. 극대점 높이만으로 첨점이라고 단정하지 않는다.
6. 0<a≤1에서 미분가능, a>1에서 미분불가능. 교사용 확인 답: 1. 학생에게 직접 공개 금지.

핵심 발상: 원래 함수의 그래프에서 x≤t까지의 최댓값을 추적하며 미분가능성에 영향을 주는 최대값 갱신 지점을 찾는다. 학생이 막히면 'g는 지금까지의 최고 기록을 그리는 함수'라고 안내한다.

## 워크북 85쪽 9번
문제: 자연수 a에 대하여 f(x)=-x^4-2x^3-x^2, g(x)=3x^2+a. 모든 실수 x에 대해 f(x)≤12x+k≤g(x)를 만족시키는 자연수 k의 개수가 3일 때 a를 구하라.

지도 흐름:
1. 자연수 a를 구하려면 가능한 자연수 k가 정확히 세 개인 조건을 찾게 한다.
2. 양변에서 12x를 빼서 f(x)-12x≤k≤g(x)-12x로 바꾼다.
3. 모든 실수 x에서 성립하려면 k가 왼쪽 함수의 최댓값 이상이고 오른쪽 함수의 최솟값 이하이어야 함을 유도한다.
4. f(x)-12x는 x=-2에서 최댓값 20을 갖는다. g(x)-12x=3(x-2)^2+a-12는 x=2에서 최솟값 a-12를 갖는다. 원문 학생 풀이의 'g의 극대점'은 '극소점'으로 수정한다.
5. 자연수 k가 20,21,22 세 개만 존재하도록 상한 a-12의 범위를 따진다. a는 자연수이므로 교사용 확인 답은 34. 학생에게 직접 공개 금지.

핵심 발상: 모든 x에서 성립하는 부등식을 수평선 k가 두 함수의 극값 사이에 있는 조건으로 바꾼다. '상수 k가 항상 두 그래프 사이에 있으려면 어느 극값을 비교해야 할까?'라고 묻는다.

## 공통 교수 전략
- 정답 및 전체 풀이를 선제적으로 노출하지 않는다.
- 단계별로 한 가지 질문만 던진다.
- 학생이 잘못 계산하면 최초 오류 지점을 짚되 고칠 기회를 준다.
- 학생이 문제를 풀면 핵심 사고 흐름을 화살표로 요약하고 검산된 변형 문제 하나를 제시한다.
