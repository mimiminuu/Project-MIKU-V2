Project MIKU - Gemini text chat edition (TTS removed)

1. Install Node.js 18 or newer.
2. Copy .env.example to .env in this folder.
3. Edit .env and replace PASTE_YOUR_GEMINI_API_KEY_HERE with your Gemini API key.
4. Run npm install (first time), then npm start.
5. Open http://localhost:25565

IMPORTANT: Never upload .env or publish API keys. If a key was shared, revoke and replace it.
Gemini model can be changed using GEMINI_MODEL in .env.
Live2D assets and existing chat UI are retained. TTS generation is disabled.
