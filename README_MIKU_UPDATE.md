# Project MIKU 수정본

- 브라우저 내장 한국어 음성 합성(Web Speech API), 음량 조절, 음성 정지
- 캐릭터 표시/숨기기, 초기 사용 안내
- 학생 주도 학습 프롬프트 및 서버 응답 버퍼링/보수적 정답 차단
- 기존 그래프 실험실 및 함수 그래프 도구 유지 (필요할 때 사용)

## 주의
정답 차단은 보수적 문자열 검사로 완벽한 보안을 보장하지 않습니다. 학습 자료/도구 결과 및 다른 서버 경로의 출력은 별도 검증이 필요합니다. 이미지 생성 API는 이 수정본에 구현되지 않았습니다. 기존 첨부 이미지 분석 기능은 유지됩니다. 브라우저 음성은 기기별 지원 음색이 다릅니다.

실행: npm install && npm start. Render 환경 변수는 기존 설정을 유지하세요. API 키를 ZIP에 넣지 마세요.
