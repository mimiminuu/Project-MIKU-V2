MIKU 로그인 없는 로컬 버전

1. 이 ZIP의 Project-MIKU-feat-demo-login 폴더를 사용하세요.
2. 기존 .env에 저장한 API 키는 새 폴더로 자동 복사되지 않습니다. 직접 안전하게 설정하세요.
3. 터미널에서 해당 프로젝트 폴더로 이동하여 npm.cmd install, npm.cmd start 실행.
4. http://localhost:25565 접속. 로그인 없이 바로 채팅 화면이 열립니다.
5. 이전 대화 기록은 local-miku 계정으로 자동 이전되지 않습니다.
6. 로그인 보호가 없으므로 인터넷에 서버를 공개하거나 외부 접속을 허용하지 마세요.
