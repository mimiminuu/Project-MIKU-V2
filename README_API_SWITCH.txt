API KEY SWITCH (no other feature changes)
1. Copy .env.example to .env (or update your existing .env).
2. Set AI_API_KEY to your Gemini key (AIza...) or OpenAI key (sk-...).
3. Restart the server. No other configuration change is required.
4. Existing GEMINI_API_KEY / OPENAI_API_KEY and LLM_PROVIDER remain supported if AI_API_KEY is not set.
5. OpenAI API requires separate API billing; ChatGPT subscription is not an API key.
6. Do not share .env or your API key.
