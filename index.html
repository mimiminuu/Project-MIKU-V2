추천 질문:
💬

01. 음성 & 텍스트 대화

  • 입력 방식: 채팅창 텍스트 입력 및 마이크(🎙️) 음성 대화
  • 실시간 피드백: TTS 음성 출력 + 입모양(립싱크) + 3D 감정 모션
  • 대화 지원: 반말, 구어체, 시험 문제 질의응답 모두 지원
📂

02. 학습 자료 첨부 (1:1 튜터링)

  • 지원 형식: PDF, TXT, MD, 소스코드, 이미지 파일
  • 첨부 방식: 클립(📎) 아이콘 클릭 또는 파일 드래그 앤 드롭
  • 정밀 분석: "5쪽 3번 문제 풀어줘"와 같이 특정 페이지 지정 가능
🤖

03. 자율 LLM 도구 호출 (Agentic AI)

  • 자연어 요청: "파이썬 실행해", "퀴즈 내줘", "검색해줘" 등 직접 발화
  • 자율 판단: 대화 맥락에 맞춰 AI가 11종 도구 스스로 선택/실행
  • 화면 연동: 퀴즈, 타이머, 그래프, 플래시카드 인터랙티브 UI 즉시 팝업
🎥

04. 3D 아바타 & 환경 설정

  • 마우스 시점 제어: 좌클릭 드래그(회전), 우클릭 드래그(이동), 휠(확대/축소)
  • 시점 리셋: 우측 상단 [시점 초기화] 버튼으로 기본 뷰 복구
  • 환경 설정: 좌측 하단 [설정]에서 다크/화이트 테마 및 TTS 모델 변경
